# /review

Run before any deploy / share:

1. `npm run build` — validator + typecheck + production build must pass.
2. `npm run preview` and click through **one full lesson** (intro → walkthrough → practice with a deliberate wrong move → quiz → done) at desktop and phone width. Confirm no console errors.
3. Re-read any **new opening content** as a 9‑year‑old would: every move has a *why*, every learner move has a hint, no jargon without a gloss.
4. Report: what was checked, what passed, anything left out.

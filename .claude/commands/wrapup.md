# /wrapup

1. **Update `PLAN.md` → Current State**: what shipped this session, what's blocked, what's next. Check off done items. Add any new decisions to the Decisions Log with the *why*.
2. **Verify**: `npm run build` passes (it runs the opening validator + typecheck).

Keep this under 2 minutes. Small decisions compound — don't skip the log.
